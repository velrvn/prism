# PRISM

**Passages Rendered In Simple Minimalism**

PRISM is an offline-first Bible reader designed for quiet, focused reading.

Live app: https://velrvn.github.io/prism

---

## About

PRISM is built around simplicity.

There are no dashboards, no clutter, and no distractions. The interface exists only to help you open scripture, read it clearly, and stay focused on the text.

The home screen presents the books of the Bible as a smooth 3D stack. Open a book, and the interface falls away into a clean reading view with serif typography and generous spacing.

The goal is not to feel like a complex app. The goal is to feel like an open page.

---

## Minimalistic Simplicity

PRISM follows a minimal design philosophy.

- Soft, muted colors
- Clean serif reading text
- Simple navigation
- No unnecessary icons
- No visual noise
- Plenty of whitespace

Every part of the interface is meant to serve the reading experience. Nothing is added unless it helps the reader.

This makes PRISM suitable for personal reading, study, memorization, and quiet reflection.

---

## Comparing Translations

PRISM includes 52 translations across many languages.

While reading a chapter, you can compare it with another translation. The comparison text appears directly beneath each verse, making it easy to see how different versions phrase the same passage.

This is useful for:

- Studying wording differences
- Reading in another language
- Comparing formal and dynamic translations
- Understanding familiar passages more deeply

The comparison view is designed to stay calm and readable. Both translations appear in the same reading flow, without splitting the screen or interrupting the text.

---

## Features

- Offline reading after translations are downloaded
- Instant switching between downloaded translations
- Selected translation is remembered after refresh or restart
- 52 translations across multiple languages
- Compare translations verse by verse
- Save verses into categories
- Add personal notes to saved verses
- Share verses as clean image cards
- Search books, chapters, and verses
- Installable as a web app
